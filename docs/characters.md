# 角色美术

Whisperville 的八位居民使用独立生成的全身立绘，整体为温暖的水粉与彩铅故事书风格。按用户最终选择，项目使用最初生成的一套形象，以年龄、发型、职业服装和道具区分角色。

## 文件与使用

- 每位角色一张 **1024 × 1536 RGBA PNG**，保留透明通道。
- `CharacterArt.jsx` 展示整张立绘；Three.js 场景通过 Sprite 使用相同原图；`Portrait.jsx` 用 CSS 复用同一图片的面部区域，不另行生成不一致的头像。
- `characters.js` 集中管理图片路径、角色编号和展示文案；游戏逻辑不依赖美术资源。
- 立绘用于地图、人物详情、消息头像、传播图谱及居民图鉴。地图改为 2.5D 手绘场景后，仍保留这套最初选定的人物形象。
- `docs/characters-preview.png` 是游戏内居民图鉴的实际截图。

## 生成记录

使用内置 **image_gen**，没有使用 API/CLI 回退。每位角色通过独立提示词生成，共享美术风格、光照与画面规格。完整提示词保存在 [character-prompts.json](character-prompts.json)，最终游戏资源位于 `public/characters/`。后续面部调整版本未用于游戏。

角色美术是 AI 生成的虚构人物，不基于真实人物照片。更换图片时保留完整头发和鞋子，使用透明背景，并同步检查头像裁切、地图小尺寸、手机布局与图鉴。
